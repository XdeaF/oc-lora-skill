# 挑图与设计审稿打分卡（OC 设计工作坊 · 阶段 8 使用）

只回答"这张图能不能用、下一步改哪里、回到哪个阶段"。不要重写整个设计。

## 一、视觉测试（可判定，不靠形容词）

| 测试 | 做法 | 通过标准 |
|---|---|---|
| 剪影测试 | 把角色涂成纯黑，只看外轮廓 | 3 秒内能认出是她，且能说出在做什么动作 |
| 缩略图测试 | 缩到 32px | 仍能分辨出主要形状块，不糊成一团 |
| 去色测试 | 转灰阶 | 明度分层仍然成立（不靠颜色硬撑结构） |
| 暖色唯一性 | 找画面暖色 | 暖色只有一处（或零处） |
| 遮挡测试 | 遮住脸 | 仍然认得出这个角色 |
| 远景测试 | 人物缩到画面 1/6 | 识别特征仍然可读 |

**遮挡测试是最狠的一条**：挡住脸还认不出，说明记忆点全押在脸和表情上，这个设计不稳。

## 二、打分卡（每项 0–3）

| 维度 | 0 分 | 3 分 |
|---|---|---|
| 剪影可读性 | 只靠配色区分 | 纯黑轮廓就认得出 |
| 色彩层级 | 颜色互相争抢 | 70/20/10 成立，暖色唯一 |
| 辨识度 | 换个发色就是别人 | 有一处无法替代的记忆点 |
| 叙事一致性 | 装备是装饰 | 每件装备都有存在理由 |
| 可复现性 | 每次出图都是新角色 | 锚点块 + 固定 seed 能稳定复现 |
| 提示词保真 | 出图与设定不符 | 逐项能对上设定表 |

判读规则：

- **任何一项 0 分 = 不合格**，不要只修最低分那项，先修 0 分
- **可复现性 0 分**：问题在阶段 7，锚点块不完整或没固定 seed
- **剪影/辨识度 0 分**：问题在阶段 2–3，**换外形，不要加细节**
- **色彩层级 0 分**：问题在阶段 4，回到配色
- **叙事一致性 0 分**：问题在阶段 5，装备缺理由

## 三、出图失败的分流

| 症状 | 真实原因 | 回到哪 |
|---|---|---|
| 每次都是新人 | 锚点块没逐字复用 / 没固定 seed | 阶段 7 |
| 瞳色左右画反 | 没写左右方向定义 | 阶段 7 |
| 服装细节各图不同 | 服装结构描述不具体 | 阶段 5 |
| 图很精致但记不住 | 没有识别特征，或特征被别处争抢 | 阶段 3 |
| 正面好看侧背崩 | 用纯文生图代替图生图 | 阶段 7 |
| 有故事感但不想看第二眼 | 缺少"代价"——她为了这个身份失去了什么 | 阶段 1 |

## 四、输出格式

必须给：**总分 + 0 分项清单 + 一条最高优先级修改 + 回到哪个阶段**。不要给一堆并列建议。
